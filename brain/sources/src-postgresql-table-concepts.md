**Source.** PostgreSQL Documentation — "Concepts" (The SQL Language tutorial).
URL: https://www.postgresql.org/docs/current/tutorial-concepts.html

**Verbatim quote (the exact supporting sentence):**

> "Each table is a named collection of rows. Each row of a given table has the same set of named columns, and each column is of a specific data type."

**Supports the factual claim that:** a table is a collection of rows; every row of a table shares the same set of named columns; and each column has a specific data type. Cited by `what-a-table-record-and-column-are` for that structure only. The page uses "row" and "column" — the everyday synonyms "record" (for a row) and "field" (for a column), and the spreadsheet comparison, are teaching framing, not taken from this page.
