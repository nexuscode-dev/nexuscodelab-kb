**Rule.** The analogy register for **AI concepts**, on the same terms as [[our-analogies-chosen-and-rejected]]: one picture per concept, recorded once, never reinvented per lesson. That note holds the web-system pictures and is at its word ceiling; [[delegation-and-review-analogies]] holds the delegation-and-review pictures, split off for the same reason at the same cap. The split is by domain, so **check all three before inventing one.**

**The house choices.**

- **Prediction vs lookup = a well-read colleague answering from memory, no phone and no notes.** Carries the boundary: fluent, usually right, occasionally mistaken without noticing.
- **Prompting = briefing a capable colleague who missed the meeting.** Clever, but absent for the context — so the context is your job.
- **Iterating = judging a colleague by their first rough draft.** Carries that the first output is a draft, not a verdict.
- **An agent = a new junior colleague with logins.** Capable, and worth the supervision of a first week.
- **MCP = a standard socket, like USB.** One shape of plug, many devices.
- **Model tiers = a three-step ladder.** Rungs outlive the names standing on them.

**The first four are deliberately one image, extended.** Same colleague throughout: answering from memory, then briefed, then drafting, then given logins. An agent *is* the same model handed tools, so it gets the same person handed keys. Do not "fix" this into four unrelated pictures — the through-line is the teaching.

**The overlap that needed a ruling.** The sibling register holds **API = a vending machine's button panel**, and MCP-as-socket is arguably one concept in two pictures. **Ruled distinct:** the panel carries *a fixed set of allowed requests*, the socket carries *one shape of plug, many devices*. A course teaching both must not blur them.

**What is missing, honestly.** No rejected alternatives were recorded while the Claude course was written, so this register carries choices without their discarded options — half of what makes the sibling note useful. Record rejections *as you choose* on the next course; reconstructing them later is guesswork.

**The misconception this pre-empts.** A wrong analogy is worse than none: it must be un-taught later.
